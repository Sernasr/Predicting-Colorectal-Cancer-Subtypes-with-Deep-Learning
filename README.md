# Predicting Colorectal Cancer Subtypes with Deep Learning

This project predicts colorectal cancer molecular subtypes using gene expression data and a deep learning model.  
The main focus is a binary classification task between CMS2 and non-CMS2 samples using a Multi-Layer Perceptron (MLP) implemented in Python/PyTorch.

## Project Overview

Colorectal cancer is a molecularly heterogeneous disease, meaning that tumors can differ strongly at the gene expression level.  
Consensus Molecular Subtypes (CMS) are used to describe these biological differences.

In this project, gene expression data is used to train and evaluate a neural network model for subtype classification.
